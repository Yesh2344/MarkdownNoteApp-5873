# MarkdownNoteApp 📓

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Bash](https://img.shields.io/badge/bash-5%2B-brightgreen.svg)](https://www.gnu.org/software/bash/)
[![Tests](https://img.shields.io/badge/tests-passing-brightgreen.svg)](./test.sh)

A **pure Bash** markdown note‑taking application that lets you:

- Create notes in a configurable directory
- List, view, and delete notes
- Export notes to HTML using **pandoc**
- Keep a tiny, human‑readable configuration (`.env`) 

All while providing robust error handling, logging, and unit‑style tests.
